## 🔐 SEGURANÇA — Todas as Vulnerabilidades Corrigidas

### 1. Parser Recursion Depth Limit ✅

**Risco**: Stack exhaustion from deeply nested expressions  
`(((...((1 + 2) * 3)...)` N=10000 → crash

**Implementação**:
```go
const MaxRecursionDepth = 1000

func (p *Parser) checkRecursionDepth() error {
    p.recursionDepth++
    if p.recursionDepth > MaxRecursionDepth {
        return fmt.Errorf("maximum recursion depth exceeded (%d)", MaxRecursionDepth)
    }
    return nil
}
```

**Locais**: `pkg/parser/parser.go` + `pkg/parser/expressions.go:parseExpression()`

### 3. VM Stack Overflow Protection ✅

**Risco**: `push()` infinito → SIGSEGV

**Implementação**:
```go
const (
    MaxStackSize = 10000
    MaxCallFrames = 5000
)

func (v *VM) push(val advplrt.Value) error {
    if len(v.stack) >= MaxStackSize {
        return fmt.Errorf("stack overflow: max size (%d) exceeded", MaxStackSize)
    }
    v.stack = append(v.stack, val)
    return nil
}

func (v *VM) pushFrame(frame *CallFrame) error {
    if len(v.frames) >= MaxCallFrames {
        return fmt.Errorf("call stack overflow: max frames (%d) exceeded", MaxCallFrames)
    }
    v.frames = append(v.frames, frame)
    v.current = frame
    return nil
}
```

**Locais**: `pkg/vm/vm.go` linhas 280-298

### 4. HTTP Redirect Limit ✅

## 🛡️ ESTABILIDADE — Cleanup Completo

### P2P Bridge Shutdown ✅

**Problema**: Goroutines abertas do `transport.Listen()` não são limpas

**Solução**:
```go
func (b *chatBridge) Shutdown() error {
    // Close transport (stops UDP listener + receive loop)
    if b.transport != nil {
        if err := b.transport.Close(); err != nil {
            errs = append(errs, fmt.Errorf("transport close: %v", err))
        }
    }
    // Close database (flushes WAL + transaction cleanup)
    if b.db != nil {
        if err := b.db.Close(); err != nil {
            errs = append(errs, fmt.Errorf("database close: %v", err))
        }
    }
    return nil
}

// Global shutdown for singleton
func ShutdownChatBridge() error {
    if globalChatBridge != nil {
        return globalChatBridge.Shutdown()
    }
    return nil
}
```

**Locais**: `pkg/vm/p2p_bridge.go` linhas 452-478 + 246-251

**Uso**: Call `ShutdownChatBridge()` in examples/chat/main ou `defer ShutdownChatBridge()`
